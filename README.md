# Recall Desk

Recall Desk is a private browser app for reminders and learning notes. It stores data in `localStorage`, so it works without a backend.

## Features

- Add reminders with date, time, details, and priority
- Mark reminders done or reopen them
- Write learning notes with category, source, and a next review date
- Review notes on a spaced schedule
- Search across reminders and notes
- Export and import JSON backups
- Optional browser notifications while the app is open

## Run

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173`.

## Build

```bash
npm run build
```
